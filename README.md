# 🦸 Superhero Battle Arena

A fast-paced 2D superhero fighting game built with **Python and Pygame**.

Choose your hero, fight through multiple levels, defeat enemies and powerful bosses, earn XP and coins, and upgrade your abilities to become the ultimate champion! ⚡🔥

---

## 🎮 Game Features

- 🦸 **4 Unique Superheroes**
  - ⚡ Thunder
  - 🔥 Flame
  - 🌑 Shadow
  - 🛡️ Guardian

- 🏟️ **8-Level Campaign**
  1. Training Ground
  2. Rookie Battle
  3. Power Awakening
  4. Combat Master
  5. Speed Master
  6. Villain's Army
  7. Elite Villain
  8. Final Boss

- ⚔️ Multiple combat abilities
  - Basic Attack
  - Special Attack
  - Block
  - Jump
  - Dash

- 👾 Multiple enemy types
- 👹 Boss battles with different phases
- 🧟 Enemy minions
- 💥 Projectiles and attack effects
- ⭐ XP and ranking system
- 🪙 Coin-based progression
- 🧪 Upgrade Lab
- 💾 Campaign save and continue system
- 🏟️ Different arena themes
- 🎵 Playful background music
- ⌨️ Keyboard controls
- 🕹️ 60 FPS gameplay

## 🎯 Controls

| Key | Action |
|-----|--------|
| ⬅️ / ➡️ | Move |
| A / D | Move |
| SPACE | Jump |
| J | Attack |
| K | Special Attack |
| L | Block |
| SHIFT | Dash |
| ENTER | Select / Continue |
| ESC | Return / Exit |

## 🏆 Progression System

Defeat enemies to earn:

- ⭐ XP
- 🪙 Coins
- 🏅 Ranks

Use your rewards in the **Upgrade Lab** to improve your hero and prepare for stronger enemies and bosses.
